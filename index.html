Technical indicator notes
Our Chart includes toggleable EMA 9/20/50, SMA 50/200, RSI 14, MACD, Bollinger Bands, Volume with SMA 20, and approximate period Support / Resistance. Saved-trade chart views also mark Entry, Targets and Stop Loss. Indicators use available historical OHLCV candles; missing volume or insufficient history can limit individual calculations. If the historical feed fails, the status below the chart identifies the sample fallback. Charts are informational, not trading signals.

About data & privacy

This is a client-side demo. Your watchlist, portfolio and preferences are saved in this browser using localStorage. No account or server is used. Do not store sensitive financial credentials here.

For production use, integrate a licensed NSE/BSE market-data provider through a secure backend. Never expose secret API keys in a public HTML file.
